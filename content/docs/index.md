## Overview

Private Chat App is a real-time chat application built with modern web technologies including:

- **Next.js** - React framework for production
- **Elysia** - Fast and friendly Bun web framework
- **Upstash Redis** - Serverless Redis for real-time messaging
- **Fumadocs** - Documentation framework
